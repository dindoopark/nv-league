# NV 내전 리그

FC Online 클럽 NV의 대규모 내전(팀리그전, 승점제) 순위표입니다.

- **순위**: 처음 오면 카드 팩을 뜯어 순위대로 팀 카드를 펼친다(3D, 다음부터는 바로 카드). 카드를 뒤집으면 그 팀의 주차별 일정. 순위표 보기도 있음. 판마다 승 3 · 무 1 · 패 0, 순위는 승점 → 골득실 → 다득점. 시즌이 끝났을 때 1위가 승점·골득실 동률이면 3:3 결정전.
- **일정**: 9주 대진표와 휴식 팀. 이번 주가 강조되고, 경기를 누르면 그 경기의 판별 결과.
- **경기표**: 9×9 대진 칸. 칸을 누르면 그 경기의 판별 결과.
- **개인**: 1·2·3티어별 판 기록.
- **결과(입력 탭)**: 누구나 경기를 골라 판별 점수를 볼 수 있다(보기 모드). 점수 칸이나 저장을 누르면 클럽 공용 비밀번호를 묻고, 맞으면 운영진(구글 시트 `설정` 탭의 명단)이 입력. 페이지에서 저장한 변경은 모두 구글 시트 `기록` 탭에 남습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면(탭·글자 정보·결과 입력) |
| `cards3d.js` | 순위 탭의 3D 카드 팩·카드(three.js). 순위 탭을 열 때만 불러오고, WebGL이 없으면 평면 카드로 바뀜 |
| `standings.js` | 순위·경기표·개인 기록 계산(순수 함수) |
| `schedule.js` | 주차별 대진표와 경기 상태 계산 |
| `teams.js`, `logos/` | 팀 이름별 로고·색 |
| `config.js` | 구글 Apps Script 웹 앱 주소. 비어 있으면 예시 데이터로 도는 데모 모드 |
| `sample-data.js` | 데모 모드 예시 데이터 |
| `apps-script/Code.gs` | 구글 시트에 붙여넣는 서버 코드 |
| `설정안내.md` | 구글 시트 연결 방법(운영자용) |
