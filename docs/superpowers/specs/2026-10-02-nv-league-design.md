# NV 내전 리그 표 — 설계

- 작성일: 2026-10-02
- 대상: FC Online 클럽 NV의 대규모 내전(팀리그전, 승점제)
- 결과물: GitHub Pages 정적 페이지 + 구글 시트 저장소(Apps Script 중계)

## 1. 목표

클럽원 누구나 폰으로 링크를 열어 순위·경기 결과를 보고, 경기를 치른 사람이 직접 결과를 입력하면 모두의 화면에 반영된다. 결과 입력은 클럽 공용 비밀번호로 보호하고, 모든 변경은 기록으로 남긴다.

## 2. 리그 규칙 (클럽 공지 기준)

- 9팀 × 3인 = 27명. 각 팀은 1·2·3티어 1명씩.
- 팀 대 팀 경기 1회 = 같은 티어끼리 1:1 세 판.
- 판마다 팀에 승 3 / 무 1 / 패 0점. 한 경기 최대 9점. 누적 승점으로 팀 순위.
- 9팀 단일 풀리그: 팀당 8경기, 전체 36경기 = 108판.
- 결과는 그 경기 6명 중 1명이 입력.
- 순위 정렬: 승점 → 골득실 → 다득점. 셋 다 같으면 공동 순위.
- 결정전: 108판이 모두 입력된 뒤, 1위 자리에 승점·골득실이 같은 팀이 2팀 이상이면 다득점은 보지 않고 "3:3 결정전 대기"로 표시한다. 운영자가 시트 `설정` 탭에 결정전 승자 팀 번호를 적으면 그 팀이 1위, 나머지가 2위가 된다.

### 팀 명단 (적힌 순서 = 1·2·3티어)

| 팀 | 1티어 | 2티어 | 3티어 |
|---|---|---|---|
| 1팀 | 스톰 | 자본 | 현우 |
| 2팀 | 범수 | 하늘 | 맹구 |
| 3팀 | 병희 | 콜드 | 쟁이 |
| 4팀 | 태현 | 태풍 | 로우 |
| 5팀 | 레오 | 로마 | 대전 |
| 6팀 | 크카모 | 원형 | 정민 |
| 7팀 | 우설 | 환타 | 울프 |
| 8팀 | 하지 | 소보로 | 레몬 |
| 9팀 | 뚝배기 | 치노 | 수프러차 |

닉네임은 `NV` 접두어 없이 표시한다. 팀 이름 기본값은 "N팀"이며 시트에서 바꿀 수 있다.

## 3. 화면 (폰 우선, 탭 4개)

1. **순위표**
   - 열: 순위 | 팀(1·2·3티어 닉네임) | 경기 | 판 승-무-패 | 승점 | 득점 | 실점 | 골득실
   - `경기` = 세 판이 모두 입력된 경기 수. 승점은 일부만 입력된 경기의 판도 포함한다.
   - 단독 1위에 ★. 결정전 대기 중에는 ★ 대신 "결정전 대기" 배지.
2. **경기표**
   - 9×9 대진 칸(행·열 = 팀 번호). 칸에 그 경기 승점 "6:3".
   - 빈 칸 = 미진행, "2/3" = 일부 판만 입력. 대각선은 비활성.
   - 칸을 누르면 그 두 팀으로 결과 입력 화면이 열린다.
3. **개인 기록**
   - 1·2·3티어별 표(각 9명): 판 승-무-패, 승점(3승+1무), 득점, 실점, 골득실.
   - 정렬: 승점 → 골득실 → 다득점.
   - 판 결과에 저장된 선수 이름 기준으로 집계한다(중간에 선수가 바뀌어도 기록이 섞이지 않음).
4. **결과 입력**
   - 팀 A, 팀 B 선택 → 티어별 3줄 자동 표시: `스톰 [ ] : [ ] 범수`.
   - 이미 저장된 판은 점수가 채워진 상태로 불러온다.
   - 입력자 선택(그 경기 6명 + "운영진"), 공용 비밀번호 입력 → 저장.
   - 판마다 독립적으로 저장된다. 화면은 불러온 값과 달라진 줄만 서버에 보낸다. 처음부터 비어 있던 줄은 보내지 않고, 기존 판의 두 칸을 모두 비우면 그 판을 삭제 요청한다. 한 칸만 채우면 오류.

공통: 상단 새로고침 버튼, 마지막 갱신 시각 표시. 대진표(주차별 일정)는 보류 — 남은 매치는 경기표 빈 칸으로 확인한다.

## 4. 구조

```
[GitHub Pages: index.html + JS]  --GET/POST-->  [Apps Script 웹 앱]  -->  [구글 시트]
        순위 계산은 브라우저에서                  비밀번호 확인·검증·잠금        팀/결과/기록/설정
```

### 파일 (저장소 `dindoopark/nv-league`, 공개)

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 뼈대와 스타일 |
| `app.js` | 탭 전환, 데이터 불러오기·저장, 화면 그리기 |
| `standings.js` | 순수 계산 함수(팀 순위, 경기표, 개인 기록, 결정전 판정). DOM·네트워크 의존 없음 |
| `config.js` | Apps Script 웹 앱 주소. 비어 있으면 예시 데이터로 동작(데모 모드) |
| `sample-data.js` | 데모 모드용 예시 결과 |
| `apps-script/Code.gs` | 시트에 붙여넣을 서버 코드(비밀번호 없음) |
| `설정안내.md` | 운영자용 구글 시트 준비 안내 |
| `tests/standings.test.mjs` | `node --test` 자동 테스트 |

### 구글 시트 탭 (`setup()` 1회 실행으로 생성·명단 채움)

| 탭 | 열 | 비고 |
|---|---|---|
| `팀` | 팀번호, 팀이름, 1티어, 2티어, 3티어 | 선수 교체 시 여기만 수정 |
| `결과` | 팀A, 팀B, 티어, A득점, B득점, A선수, B선수, 수정시각, 입력자 | 한 판 = 한 줄. 팀A < 팀B로 정규화. 같은 (팀A, 팀B, 티어)는 덮어씀 |
| `기록` | 시각, 입력자, 팀A, 팀B, 티어, 이전, 이후 | 추가만 함. 삭제는 이후="삭제" |
| `설정` | 결정전 승자 팀 번호 | 비어 있으면 미정 |

비밀번호는 시트가 아닌 Apps Script **스크립트 속성** `PIN`에 둔다(시트를 공유받은 사람도 볼 수 없음). 6자리 이상 권장.

### API

- `GET ?action=data` → `{ ok, teams:[{no,name,players:[t1,t2,t3]}], games:[{a,b,tier,ga,gb,pa,pb,at,by}], settings:{playoffWinner}, serverTime }`
- `POST` (본문은 `text/plain`의 JSON — CORS 사전 요청 회피)
  `{ action:"save", pin, by, a, b, games:[{tier, ga, gb}] }` (`ga`/`gb`가 둘 다 `null`이면 삭제 요청)
  → 성공 `{ ok:true, data:<GET과 같은 형태> }`, 실패 `{ ok:false, error:"PIN"|"INVALID", message }`
- 서버 검사: 비밀번호 일치 / 팀 번호 1~9이고 서로 다름 / 티어 1~3 / 점수 0~30 정수 / 입력자가 그 경기 6명 중 1명 또는 "운영진". `a > b`로 오면 팀과 점수를 함께 뒤집어 저장. 값이 그대로인 판은 기록하지 않음.
- 동시 저장: `LockService`로 한 번에 하나씩 처리.

## 5. 오류 처리

- 비밀번호 틀림·검증 실패: 메시지 표시, 입력값 유지.
- 저장 중 네트워크 오류: "다시 시도" 버튼, 입력값 유지.
- 불러오기 실패: 브라우저에 저장해 둔 마지막 데이터를 보여 주고 "최신 아님" 표시. 저장된 데이터도 없으면 안내 문구.
- 잘못된 입력·장난: `기록` 탭으로 추적하고, 운영자가 시트 `결과` 탭에서 직접 되돌린다.

## 6. 운영자 준비 (1회)

1. 새 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 붙여넣기.
2. `setup` 함수 실행(권한 허용) → 탭 4개와 명단 생성.
3. 프로젝트 설정 → 스크립트 속성에 `PIN` 추가.
4. 배포 → 웹 앱(실행: 나, 액세스: 모든 사용자) → 웹 앱 주소 복사.
5. 주소를 Claude에게 전달 → `config.js`에 넣고 push.

## 7. 검증

- `standings.js` 자동 테스트: 승점·골득실·다득점 정렬, 공동 순위, 일부 판만 입력된 경기(`경기` 수 미포함·승점 포함), 시즌 완료 후 1위 동률 → 결정전 대기, 결정전 승자 지정 반영, 팀A/팀B 뒤집힘 처리, 개인 기록 집계.
- 데모 모드로 폰 크기(375px) 화면 확인.
- 시트 연결 후 실제 저장·수정·삭제·비밀번호 틀림 각 1회 확인, `기록` 탭에 남는지 확인.

## 8. 범위 밖

- 주차별 대진표: 일정 확정 후 추가 요청 시 `일정` 탭으로 확장.
- 결정전 경기 결과 입력 화면(시트 `설정` 칸으로 대체), 알림, 개인 로그인.
